Shiki grammars and themes in the DevHub App Shell
=================================================

The transcript of a GUI Agent colours code with these TextMate grammars and
these two themes, as Shiki 4.4.3 packages them (`@shikijs/langs`,
`@shikijs/themes`). Shiki takes them from tm-grammars 1.32.22 and tm-themes
1.12.12, whose NOTICE files carry each one's source and licence; the sections
for exactly the grammars and themes DevHub bundles are reproduced below as
those NOTICE files give them. No other grammar or theme is in the bundle.
