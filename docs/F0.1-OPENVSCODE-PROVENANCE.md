## Reproduction

Run the script from a macOS arm64 checkout. It clones only the pinned upstream
tag into a temporary work root, verifies the upstream Node archive checksum,
installs the exact build toolchain, runs `npm ci` and
`vscode-reh-web-darwin-arm64`, and writes no source or generated bundle
into this repository.

```sh
python3 scripts/openvscode-darwin-arm64-provenance.py \
  --work-root "$(mktemp -d -t devhub-openvscode-f01)" \
  --ledger provenance/openvscode-darwin-arm64.json
```

The ledger contains only relative artifact names, versions, hashes, counts,
and pass/fail statuses. It never stores a connection token, response body,
server log, absolute temporary path, or machine identifier.

## Required hosted evidence

The successful run must expose the Actions URL and status, upload artifact
digest, archive SHA-256, bundle manifest SHA-256, executable Mach-O arm64
checks, all upstream lockfile hashes, source and bundled license inventory,
Node/pnpm/Rust/macOS/Xcode provenance, cache key inputs, and passing checks for
`--help`, unauthenticated rejection, authenticated folderless/folder loopback
HTTP, WebSocket upgrade, and shutdown. No release tag or GitHub Release is
created by this workflow.
