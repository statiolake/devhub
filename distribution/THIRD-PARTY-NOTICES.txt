DevHub 0.1.0 — third-party notices
===================================

This notice accompanies the DevHub macOS application bundle. Every licence
text it names ships inside the bundle, in
`DevHub.app/Contents/Resources/licenses/`.

Shipped application components
------------------------------

* DevHub — the App Shell, the main process and the DevHub Bridge built-in
  extension. MIT; see `licenses/DevHub-MIT.txt`.
* Code - OSS (Microsoft Visual Studio Code, the open-source distribution),
  pinned as the `vscode` submodule — MIT; see `licenses/Code-OSS-MIT.txt`. The
  bundle carries its compiled `out/`, its production dependencies and its
  built-in extension set. Their own notices are reproduced verbatim in
  `licenses/Code-OSS-ThirdPartyNotices.txt`.
* Electron, as staged by VS Code's own build — MIT; see
  `licenses/Electron-MIT.txt`. Electron embeds Chromium and Node.js, whose
  notices are the ones Electron ships.
* React 19.1.1 and React DOM 19.1.1 — MIT; see `licenses/React-MIT.txt`.
* `@xterm/xterm` 6.0.0 and `@xterm/addon-fit` 0.11.0 — MIT; see
  `licenses/Xterm-MIT.txt`.
* minimist 1.2.8, toml-eslint-parser 1.0.3 and eslint-visitor-keys 5.0.1 — MIT.
  The main process imports these three at runtime.

Ported source
-------------

* herdr — Apache License 2.0; see `licenses/herdr-Apache-2.0.txt`. No code from
  herdr is linked or redistributed. DevHub's agent status detection
  (`apps/desktop/src/main/agent/detect/`) is a TypeScript port of herdr's rule
  model from `src/detect/mod.rs` and `src/detect/manifest.rs`, and carries the
  rules of its `claude` and `codex` screen manifests
  (`src/detect/manifests/claude.toml` 2026.08.13.1 and
  `src/detect/manifests/codex.toml` 2026.08.09.1). Each ported file names herdr
  and this licence in its header. herdr ships no NOTICE file, so there is no
  attribution notice to reproduce beyond this entry and the licence text.
* Octicons 19.33.0 (GitHub Inc.) — MIT; see `licenses/Octicons-MIT.txt`. The
  Octicons package is not a dependency and none of it is installed or linked.
  DevHub's Sidebar carries four of its icon outlines verbatim as inline SVG
  path data — `issue-opened-16`, `issue-closed-16`, `git-pull-request-16` and
  `git-pull-request-draft-16` — in
  `apps/desktop/src/shell/components/sidebar/Sidebar.tsx`, which names Octicons
  and this licence where they appear.

Build-only tools — Vite, TypeScript, ESLint, Prettier, esbuild and the rest of
the toolchain — are not part of the bundle and are not represented here.

What changed from 0.1.0's first notice
--------------------------------------

An earlier revision of this file described a Tauri application that treated
Visual Studio Code as a separately installed prerequisite. That is no longer
what DevHub is: the application is built on VS Code's own Electron and ships
Code - OSS inside its bundle. Tauri and WRY are gone, and so are their notices.
The editor is no longer a BYO dependency, and no official Microsoft-branded
build of Visual Studio Code or its server is redistributed.
