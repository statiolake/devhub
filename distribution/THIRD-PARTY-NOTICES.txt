bundle and are not represented as runtime components here.

Provider boundary
-----------------

The official Microsoft Visual Studio Code application and its `code serve-web`
server are BYO dependencies. They are not bundled, downloaded, patched, or
redistributed by DevHub, so their terms and notices are not part of this
distribution. A user must install a supported official VS Code application
separately when selecting that provider; the corresponding CLI must expose
`code --version` and `code serve-web --help`. DevHub does not accept the
official Server license on the user's behalf.

The legacy OpenVSCode/Node payload and its notices are also absent from this
local App Shell bundle. They must not be inferred from this notice or from the
Bridge VSIX. A future bundle that ships either provider needs a separate,
provider-specific provenance and license inventory before distribution.
